详情

postgres-mcp 通过一个只读数据库账号连接 PostgreSQL，向客户端暴露三个工具：列出 schema、读取表结构、执行 SELECT。写语句在解析阶段被拒绝，单次查询默认限制返回 500 行。

适合的场景

  • 让模型在回答前先查看真实的表结构，减少臆造的列名。
  • 在本地开发库上做探索性查询与数据核对。

配置示例

{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "postgres-mcp", "postgresql://readonly@localhost/app"]
    }
  }
}

连接串由使用者自行在本地客户端配置，本站不保存任何密钥，也不代为调用。
