它做什么

postgres-mcp 用一个只读数据库账号连接 PostgreSQL，向客户端暴露三个工具：列出 schema、读取表结构、执行 SELECT。写语句在解析阶段就被拒绝，单次查询默认最多返回 500 行。

适合的场景

  • 让模型在回答之前先看一眼真实的表结构，少编造几个列名。
  • 在本地开发库上做探索性的查询和数据核对。

配置示例

{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "postgres-mcp", "postgresql://readonly@localhost/app"]
    }
  }
}

连接串由你在自己的客户端里配置。这个站点不保存任何密钥，也不替你调用它。
