tidewatch

采集 GitHub 仓库指标并保存每日快照，用快照相减计算 7 天和 30 天增长；数据不足时如实标注，而不是显示 0。

为什么做它

GitHub 页面只显示当前 Stars，看不出最近一周涨了多少。tidewatch 每天在固定的 UTC 时间窗口抓取一次指标，保存为快照，增长由两份快照相减得到。

它怎么工作

  1. 按配置的 topic 白名单发现候选仓库，排除 fork 与已归档仓库；
  2. 以仓库 ID 去重，抓取 Stars、Forks、Open Issues 与最近 release；
  3. 一批全部成功才发布，部分失败则保留上一次完整榜单。
$ tidewatch run --window 2026-11-20
discovered 1,284 repos · fetched 1,284 · rate-limit remaining 3,912
batch 2026-11-20 committed

已知限制

样本少于 7 天的仓库会标记为「数据不足」。负增长会保留，不会被截断为 0。
